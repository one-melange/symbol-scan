## Convention

- Sections by horizon: **Now** (actively being worked), **Next** (queued), **Later**
  (someday/maybe), **Done** (shipped).
- One line per item: `- [ ] (Txx) Short title — one-line why · file:line`
- When an item ships, check it off and move it to **Done** with the commit/PR ref.
- IDs (`Txx`) are stable — don't renumber. New items get the next free number.
- `(verified)` = confirmed against source. `(reported)` = surfaced by audit, line refs
  not yet verified.

- [x] (T6) Configurable hotkey — the trigger keys are now user-rebindable with a live UI, replacing the hardcoded `@`/`#`/`⌘⇧O` branches. Introduced a data-driven, **pure** model in `EventTap.swift`: `HotkeyBinding` (keyCode + a `Codable` `HotkeyModifiers` OptionSet), a `TriggerAction` (`claudeAt`/`codexHash`/`openSymbol`, each with a fixed injected `marker`) that replaces the old `Trigger` enum's semantic role, and `HotkeyMatcher.match` — the seam that makes the CGEventTap callback a thin wrapper and the whole matrix unit-testable. Matching is **exact modifier-set equality** (not the old `contains` ladder), so ⌘⇧2 no longer incidentally fires the bare-⇧ `@` binding; the legacy ctrl-variant branches were dropped. Persistence mirrors `RepoPreference`: `HotkeyPreference` stores one JSON blob under `SymbolScan.hotkeyBindings` with an injectable `UserDefaults` and a pure `decode` that falls back to `.defaults` on missing/corrupt data. - [x] (T4) Incremental reindex on save — a new `RepoWatcher` (single FSEvents stream, `FileEvents`+`NoDefer`+`WatchRoot`, 0.3s coalescing latency, dispatch-queue scheduled) watches the active repo and drives a **per-file** splice, so a file an editor/agent writes becomes searchable in ~1s with no manual Reindex. - [x] (T8) Language coverage — JS/JSX closed. `.js`/`.jsx`/`.mjs`/`.cjs` now index via a new `.javascript` dialect backed by `tree-sitter-javascript` (exact 0.23.1, matching the sibling grammars' vintage). `.jsx` needs no separate grammar — unlike TS/TSX, the JavaScript grammar parses JSX natively. The JS query is deliberately **not** a copy of the TS one: JS names classes with `(identifier)` where TS uses `(type_identifier)`, and has no `interface_declaration`/`type_alias_declaration`/`abstract_class_declaration`, so a copied query would fail to compile and (post-T21) silently zero out every `.js` file. Minified/generated JS is screened out in two layers, because `git ls-files` doesn't honour `RepoScanner.excludedDirs`: a cheap name check (`*.min.js`, `*.bundle.js`) in `Language.detect` that avoids the read entirely, and — since name patterns miss the common case, Vite emits `index-DJ7HgGZS.js` — a `SymbolParser.isMinified` content check that skips any source whose longest line exceeds 5,000 characters.
